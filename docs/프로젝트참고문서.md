### 참고한 패키지 공식문서
프로젝트 개발 및 유지보수에 참고할 수 있는 공식 문서와 라이브러리 링크를 정리했습니다.

#### 1. Django & Web
- [Django](https://docs.djangoproject.com/en/4.2/) - 웹 프레임워크
- [django-htmx](https://django-htmx.readthedocs.io/) - Django와 HTMX 통합
- [django-filter](https://django-filter.readthedocs.io/) - 필터 기능을 쉽게 구현

#### 2. Testing
- [pytest-django](https://pytest-django.readthedocs.io/) - Django용 pytest 플러그인
- [factory_boy](https://factoryboy.readthedocs.io/) - 테스트 데이터 자동 생성
- [pytest](https://docs.pytest.org/) - Python 테스트 프레임워크
- [htmx](https://htmx.org/) - 서버-클라이언트 간 비동기 요청을 간단하게 처리
- [Plotly Express](https://plotly.com/python/plotly-express/) - 인터랙티브 차트 시각화

#### 3. UI & 디자인
- [Heroicons](https://heroicons.com/) - 아이콘 라이브러리
- [DaisyUI](https://daisyui.com/) - TailwindCSS 기반 UI 컴포넌트
- [TailwindCSS](https://tailwindcss.com/) - 유틸리티 기반 CSS 프레임워크
